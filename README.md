## The pitch

> We mail offices one live bee a month; they pay $49 a seat because no meeting in history has ever survived a bee, and every bee flies home to a hive we own, ready to ship again.

## How it runs

`main.py` (Python standard library only) writes the pitch to the entry
output path — `ENTRY_OUTPUT` if set, else `entry.txt` inside
`OUTPUT_DIR`/`MAKEFUN_OUTPUT_DIR`, else `/output/entry.txt` — and marks
the file readable (mode 0644). `entry.txt` holds the same sentence for
reference.
